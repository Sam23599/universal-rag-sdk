# Changelog

All notable changes to this project will be documented here.

## Unreleased

- Install `pypdf` with the core SDK so the default PDF parser works after a standard installation.
- Document direct GitHub installation, editable development setup, dependency handling, and import verification.

## 0.1.0 - 2026-09-18

- Added modular ingestion, parsing, cleaning, deduplication, chunking, and enrichment.
- Added immutable versioned indexing with BM25 and optional dense retrieval.
- Added query preprocessing, ACL and metadata filtering, reranking, and context construction.
- Added grounded generation with citation and numeric-claim validation.
- Added caching, retries, feedback storage, observability hooks, and evaluation metrics.
